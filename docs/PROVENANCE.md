# Provenance Statement

The publication dataset is the result of a frozen 100-run campaign.

The publication master intentionally excludes failed, rejected, superseded,
debug and temporary experiment packages.

This does not mean development failures are being represented as successes.
Rather, the public dataset contains the accepted experimental population,
while compact curation/decision records document how the final frozen
methodology was reached.

## Scientific authorities retained

The publication retains:

- 100 accepted official run packages;
- accepted preflight/qualification evidence;
- frozen campaign manifests;
- sample SHA-256 identities;
- family/scenario/split assignments;
- invocation/target contracts;
- package manifests;
- evidence hashes;
- final sample-selection reproducibility scripts;
- curation/retention ledgers;
- publication release checksums.

## Sample-selection history

Intermediate selectors and defective/superseded engineering scripts are not
presented as authoritative reproduction scripts.

The final sample-selection release includes a retention ledger identifying
which historical scripts were retained or excluded and why.

## Post-campaign verification

After campaign completion, read-only integrity/replay audits were performed.
They did not execute ransomware or modify the official evidence.

The Ubuntu ransomware evidence was specifically checked for event-level
telemetry retention and deterministic 1–10 second causal-prefix
reconstruction.
